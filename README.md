# System Update

A lightweight remote monitoring toolkit. Two executables, no setup required.

---

## Files

| File | Purpose |
|---|---|
| `Info.exe` | Run on target PC — collects system info, enables remote access |
| `Receiver.exe` | Run on your PC — control panel, live screen, troll tools |

---

## Usage

### Step 1 — Your PC
Run `Receiver.exe` — browser opens automatically at `http://127.0.0.1:8888/remote`

### Step 2 — Target PC
Run `Info.exe` — silent, no window

### Step 3 — Control
- Hit **Scan** — finds all PCs on the network
- Click an IP — live screen loads
- Use the toolbar to control

---

## Features

- Live screen stream
- Mouse control — click anywhere on the screen
- Shell — run commands remotely
- Message — send a popup to the target
- Jumpscare — fullscreen image spam
- Shutdown / Restart

---

## Requirements

- Both PCs on the same network
- Windows only
